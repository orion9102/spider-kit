spider-kit 是一个插件化爬虫。页面上选插件、填配置、点开始，就能看日志和结果。当前内置三个插件：静态网页、JSON API、GitHub。

1. 打开哪里

公网：https://spider-kit.909939.xyz/

局域网：http://192.168.88.47:3241/

页面和接口目前没有登录。知道地址的人都能下任务，不要填会泄露的密钥；GitHub Token 优先用服务器上的 GITHUB_TOKEN 环境变量。

2. 页面怎么用

  1. 左侧点一个插件。表单按这个插件的配置项生成，带红色星号的是必填。
  2. 填值。数字直接写数字；布尔写 true 或 false；数组和对象写 JSON，例如 ["https://example.com"]。
  3. 点「开始爬取」。中间运行记录会出现一条「运行中」。
  4. 点这条记录。右侧上方是实时日志，完成后下方出现结果表，最多显示前 500 条。

一次只建议跑一个任务。刷新页面不会中断正在跑的任务，但运行记录存在服务进程里，容器重启后列表会清空；已经写出的结果文件还在服务器的 output/ 目录。

3. 三个插件

static-site · 静态网页

抓服务端返回的 HTML，不执行页面里的 JavaScript。适合结构固定、链接能直接打开的站点。

字段必填怎么填
startUrls是种子地址数组
itemSelector否每条记录的 CSS 容器，如 .quote
fields否{"标题":"h2","链接":"a@href"}。@ 后面是属性名
maxRequests否最多请求数，默认 100
linkSelector否继续发现链接的选择器，默认 a[href]
allowedGlobs否允许继续抓的范围，默认只留在种子站点内
respectRobots否默认 true，遵守 robots.txt
{
  "startUrls": ["https://quotes.toscrape.com/"],
  "itemSelector": ".quote",
  "fields": {"text": ".text", "author": ".author", "firstTag": ".tag"},
  "maxRequests": 3
}

api-json · JSON 接口

直接请求返回 JSON 的地址，并可按页码翻页。空页默认停止。

字段必填怎么填
startUrls是接口地址数组
itemPath否条目在 JSON 里的路径，如 data.items。留空表示整个响应就是条目
pageParam否页码参数名。留空则不翻页
startPage否起始页，默认 1
maxPages否最多翻几页，默认 1
headers否附加请求头，JSON 对象
stopOnEmpty否空页是否停止，默认 true
{
  "startUrls": ["https://jsonplaceholder.typicode.com/posts"],
  "pageParam": "_page",
  "startPage": 1,
  "maxPages": 2
}

github · GitHub

只访问 api.github.com。三种模式：搜仓库、列用户仓库、列 Issues。

字段必填怎么填
mode是search-repos、user-repos 或 repo-issues
query搜仓库时GitHub 搜索语法，如 crawler language:typescript
user列仓库时用户或组织名
repo列 Issues 时owner/name
limit否最多保留多少条，默认 50
token否不填则使用环境变量。匿名额度很低
{
  "mode": "search-repos",
  "query": "web crawler language:typescript",
  "limit": 10
}

4. 结果在哪

页面表格只是预览。完整结果在当次输出目录：

items.json 是缩进数组，items.jsonl 是一行一条。manifest.json 记录配置、起止时间和统计，Token 会脱敏。

网页条目会自动带上 __pageUrl 和 __scrapedAt。

5. 命令行

同一套插件也能在本机跑。先在项目目录执行 npm install 和 npm run build。

node dist/cli.js list
node dist/cli.js info static-site
node dist/cli.js run static-site -c examples/quotes.json
node dist/cli.js run github --set mode=search-repos --set 'query=gcpp' --set limit=10

本地 Web 调试用 npm run web，默认只听 127.0.0.1:3210。

6. API

程序调用看 Scalar API 文档。规范文件在 /openapi.json。下任务用 POST /api/runs，随后用返回前的运行列表找到 runId。

7. 现在做不到

  • 不渲染 JavaScript，打不开需要浏览器执行后才有内容的页面。
  • 不登录、不保持 Cookie、不处理验证码。
  • 没有定时任务、增量去重、代理池。
  • 不抓需要绕过登录墙、付费墙或明确禁止抓取的站点。
